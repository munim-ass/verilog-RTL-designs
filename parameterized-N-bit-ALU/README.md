Parameterized N-bit ALU in Verilog
--Overview

This project implements a parameterized N-bit Arithmetic Logic Unit (ALU) in Verilog HDL.
The design supports configurable bit-width and multiple arithmetic & logical operations.

The ALU is fully synthesizable and simulation verified.

Features --

Parameterized bit width (default: 8/16/32 bits)

Arithmetic Operations:
Addition
Subtraction

Logical Operations:
AND
OR
XOR
NOT
Zero flag generation
Carry 
Overflow 

Design Highlights :
Modular RTL design
Clean case-based operation selection
Fully synthesizable
Testbench with multiple edge-case verification

Tools Used :
Verilog HDL
Vivado Simulator
